Smooth Scroll UI – Day 4

A modern React UI built with Vite, featuring smooth scrolling (Lenis), custom animated cursor, marquee animation, and SCSS-based styling.
This project focuses on clean components, micro-interactions, and a premium frontend experience.

🚀 Features

Smooth scrolling with Lenis

Custom animated cursor

Eye-tracking animation

Infinite marquee text

SCSS modular styling

Fast Vite setup

🛠️ Tech Stack

React

Vite

SCSS

Lenis

JavaScript (ES6+)

▶️ Run Locally
npm install
npm run dev
